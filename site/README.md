# 兵庫県1泊2日 視察研修・参加者案内

2026年12月19日（土）〜20日（日）、9名予定の旅行案内です。HTML / CSS / JavaScriptだけで動作し、ビルドやパッケージのインストールは不要です。

## ローカルで確認

リポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

同じ端末のブラウザで `http://127.0.0.1:8000` を開きます。クラウド環境では利用可能なプレビュー機能に従ってください。停止は Ctrl+C。

## 編集箇所

- `data.js`：両日の行程、希望者向け参考ルート、施設、お知らせ、緊急連絡先。
- `index.html`：タイトル・日程・人数、重要事項のまとめ、ホテル詳細、固定案内文。
- `style.css`：先頭のCSS変数で色、角丸を変更。スマホを優先した文字サイズとナビゲーション。
- `app.js`：データを画面へ表示する処理。テキストは `textContent` で挿入。

重要事項のまとめは行程とは別にHTMLへ記載しています。集合・出航・帰りの列車やホテルを変更した場合は、`data.js` と `index.html` の両方を更新してください。

お知らせは `announcements` に `{title: 'タイトル', body: '本文'}` を追加します。連絡先は `contacts` に `{name: '幹事名', phone: '確認した電話番号'}` を追加します。公開する本人の同意を得た実在の番号だけを登録してください。空のままでもレイアウトは成立します。

施設の `query` はGoogleマップの検索語です。「現在地から向かう」はGoogleマップへ遷移し、出発地をそちらで指定・取得します。サイト自体は位置情報を取得しません。地図は通信が必要です。

「予約済」はユーザーから予約済みと提供されたクルーズのみ。「仮予定」は夕食。「集合時刻」は旅程で指定された集合を示し、列車や施設の予約確認を示しません。

## 公開例：GitHub Pages

1. `site` 内の全ファイルをリポジトリへコミット・pushします。
2. 公開用ブランチ（例：`gh-pages`）のルートに `site` の内容を配置します。`index.html`、`data.js`、`app.js`、`style.css` を同じ階層に保ちます。
3. GitHub のリポジトリ Settings → Pages → Deploy from a branch で、そのブランチの `/ (root)` を選択・保存します。
4. GitHub が表示する公開URLで、スマホの日程・固定ナビ・地図リンクを確認します。

または静的ホスティングサービスへ `site` フォルダを公開できます。ビルドコマンドは不要です。この作業では公開・pushは実施していません。

静的サイトには参加者認証がありません。参加者限定での運用が必要な場合は、認証機能のある公開先を選び、個人情報や連絡先の公開範囲を確認してください。
